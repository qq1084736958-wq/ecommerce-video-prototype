# AI 商品短视频生成工作台 PRD

> 面向电商商家、跨境卖家与内容营销团队的多平台商品视频生产工具

## 1. 摘要

本产品是一款网页端 AI 商品短视频生成工作台。用户上传商品图片、填写或粘贴商品卖点，选择目标平台后，系统生成可确认的视频脚本，并输出适配抖音、小红书、TikTok、Instagram Reels 和 YouTube Shorts 的商品短视频。

产品不与通用 AI 视频平台竞争底层模型能力，而是聚焦电商营销工作流，解决商品信息难以转成视频脚本、多平台内容重复制作、跨境文案本地化成本高，以及成功视频难以复用的问题。

最小可行版本的核心验证路径为：

```
商品图片与卖点
→ AI 结构化商品信息
→ 生成并确认脚本
→ 推荐模板
→ 生成多平台版本
→ 预览与下载
→ 制作同款
```

## 3. 产品背景

### 3.1 背景与机会

电商营销越来越依赖短视频内容。商家不仅需要商品主图和详情页，还需要持续生产商品展示、新品发布、限时促销和种草推荐视频。跨境卖家还需要为海外平台制作英文版本。

很多商家已经有商品主图、细节图、包装图和场景图，但从静态素材到可发布短视频，中间仍包含脚本、分镜、字幕、模板、语言、比例和导出等工作。通用 AI 视频工具能生成画面，却不一定能直接完成这条电商工作流。

本项目的机会不是再做一个“能生成视频”的平台，而是把商品信息、营销目标和平台规则结构化，让用户在更短路径内获得可用结果。

### 3.2 用户问题

#### 问题一：有商品图，但缺少短视频素材

商家通常已经拥有商品主图、详情页图和场景图，但缺少动态内容。静态图片难以直接满足短视频平台持续发布和广告测试的需要。

#### 问题二：商品视频制作成本高

传统流程需要脚本、拍摄、剪辑、字幕、配乐和多版本导出。小团队缺少专职人员，大团队也面临商品多、平台多、更新快带来的产能压力。

#### 问题三：商品卖点难以转成短视频脚本

“防水、轻便、大容量”是商品信息，不是完整的视频表达。视频仍需要开头钩子、商品展示顺序、场景、字幕和行动引导。

#### 问题四：多平台适配重复劳动

同一商品在不同平台需要不同的节奏、字幕长度、标题语气和行动引导。简单复制同一条视频，无法体现平台差异。

#### 问题五：跨境本地化不等于直译

跨境内容需要在保留商品事实的同时，调整字幕长度、表达语气、钩子和行动引导。逐字翻译容易生硬，也可能造成事实偏差。

#### 问题六：成功视频难以批量复用

当一个模板或视频结构表现良好，用户希望替换商品图和卖点继续生产，而不是重新填写全部参数。

### 3.3 为什么是现在

- AI 已能够辅助提取商品信息、生成脚本、改写多平台文案和驱动视频生成；
- 商品视频生产仍包含大量重复、结构化的操作，适合被 AI 工作流自动化；
- 多平台和跨境运营使“一份商品信息，多版本输出”的需求更明显；
- 底层模型能力逐步商品化后，产品层的差异更多来自场景理解、流程控制、结果复用和成本管理。

### 3.4 竞品环境下的产品判断

文生视频、图生视频、模板和重新生成已经属于行业基础能力，不能作为独占创新。本产品的差异化假设是：

1. 以商品信息表单代替空白提示词，降低输入门槛；
2. 先生成并确认脚本，再生成视频，降低商业信息错误；
3. 由主脚本派生平台适配脚本，减少重复制作；
4. 中英文对照确认，控制本地化风险；
5. 以商品项目组织多平台版本，而不是把结果平铺成文件；
6. 通过制作同款，把满意结果转为可复用生产方法。

以上均为待验证假设，不将其描述为市场上从未出现的功能。

### 3.5 约束

- 最小可行版本每个任务只处理一个商品；
- 每次最多选择 3 个平台；
- 每次最多生成 6 条视频；
- 每个商品上传 1–5 张图片；
- 最小可行版本只支持中文和英文；
- 最小可行版本不读取商品详情页链接，只支持粘贴文本；
- 输出质量受底层视频模型、素材质量和模板能力影响；
- 商品价格、参数、认证、功效和促销信息必须由用户确认，AI 不得自行创造。

## 4. 产品目标

### 4.1 产品目标

降低商品短视频的制作门槛，提高电商营销素材在多平台、多语言、多版本场景下的生产效率，并验证用户是否愿意复用 AI 生成的商品视频结构。

### 4.2 用户目标

用户不需要学习复杂剪辑工具，即可完成：

1. 上传商品图片；
2. 填写或粘贴商品卖点；
3. 选择目标平台；
4. 确认 AI 生成的商品脚本；
5. 选择模板并生成视频；
6. 预览、编辑字幕和下载；
7. 基于满意结果制作同款。

### 4.3 业务目标

- 验证商品视频工作流是否比通用提示词输入更容易完成；
- 验证多平台版本是否能提高单个商品项目的使用价值；
- 验证中英文本地化是否能吸引跨境卖家；
- 验证制作同款是否能带来持续使用和更多生成消费；
- 建立订阅套餐加额度包的商业化基础。

### 4.4 最小可行版本关键结果

以下数值为作品集阶段的建议验证目标，需在可用性测试和内测后校准，不代表已获得真实数据。

| 关键结果 | 指标定义 | 建议验证目标 | 说明 |
|---|---|---:|---|
| 关键结果一 | 首条视频生成完成率 | ≥ 45% | 进入新建流程的新用户中，成功生成至少一条视频的比例 |
| 关键结果二 | 视频下载率 | ≥ 30% | 成功生成的视频中，被下载的视频比例 |
| 关键结果三 | 多平台任务全部完成率 | ≥ 90% | 多平台任务中，所有目标平台均成功生成的比例 |
| 关键结果四 | 制作同款使用率 | ≥ 15% | 查看已完成项目后点击制作同款的项目比例 |
| 关键结果五 | 首次任务中位完成时长 | ≤ 12 分钟（不含模型排队异常） | 从开始填写到任务提交并获得首条结果 |

### 4.5 非目标

最小可行版本不验证以下目标：

- 专业剪辑能力是否能替代剪映、Premiere 等工具；
- 企业级团队协作、权限和审批；
- 广告素材投放后的点击率、转化率自动优化；
- 一键发布到外部平台；
- 多商品批量生产；
- 所有商品品类的高质量模板覆盖。

## 5. 目标市场与用户分层

市场分层以用户要完成的任务为依据，而不是以企业规模为唯一标准。

### 5.1 P0：电商商家与跨境卖家

**典型用户：** 抖音小店、淘宝 / 天猫、拼多多、小红书店铺、TikTok Shop、Shopify、Amazon 和独立站卖家。

**核心任务：** 用已有商品素材快速生成可发布的视频，降低拍摄和剪辑成本。

**关键约束：**

- 内容制作资源有限；
- 商品事实和促销信息不能出错；
- 同一商品常需多个平台版本；
- 跨境用户需要英文内容；
- 生成成本需要可预期。

### 5.2 P0：内容运营与社媒运营团队

**典型用户：** 电商内容运营、品牌社媒运营、商品运营、海外社媒运营和短视频运营。

**核心任务：** 持续生产商品内容，为不同平台调整脚本、字幕和视频版本。

**关键约束：**

- 内容更新频率高；
- 历史素材和成片分散；
- 高表现结构难复用；
- 多平台重复制作耗时。

### 5.3 P1：品牌营销与代运营团队

**核心任务：** 为多个商品或客户生产营销素材并沉淀模板。

**暂不满足的需求：** 团队空间、客户隔离、品牌资产、成员权限、审批流和批量任务。因此该群体不是最小可行版本的首要留存对象。

### 5.4 P2：MCN 与广告素材团队

**核心任务：** 大规模生产并测试买量素材。

**暂不满足的需求：** 素材组合、投放数据回流、自动实验、素材疲劳分析和高并发批处理。作为未来扩展市场，不进入最小可行版本核心范围。

### 5.5 最小可行版本优先商品品类

产品原则上支持全品类，但模板先覆盖以下四类：

| 品类 | 主要展示重点 | 优先模板方向 |
|---|---|---|
| 美妆护肤 | 质感、成分、使用效果、精致氛围 | 种草、新品发布、产品特写 |
| 服饰鞋包 | 款式、材质、颜色、穿搭场景 | 商品展示、生活方式、上新 |
| 家居日用品 | 功能、使用场景、前后差异 | 功能展示、种草、促销 |
| 3C 数码 | 外观、功能、参数、使用体验 | 新品发布、细节展示、促销 |

其他品类可使用通用模板，效果差异需要在界面中合理管理预期。

### 5.6 核心营销场景

| 场景 | 用户目标 | 推荐结构 |
|---|---|---|
| 商品展示 | 将静态商品图转成动态展示视频 | 外观 → 细节 → 卖点 → 行动引导 |
| 新品发布 | 为新商品生成预热或首发内容 | 新品亮相 → 核心亮点 → 场景 → 行动引导 |
| 限时促销 | 结合折扣和时间生成促销内容 | 促销钩子 → 商品 → 价格 → 截止时间 → 行动引导 |
| 种草推荐 | 用自然内容表达商品价值 | 用户痛点 → 使用场景 → 推荐理由 → 柔性行动引导 |

## 6. 价值主张

### 6.1 核心价值主张

| 用户任务 | 当前痛点 | 产品能力 | 用户收益 |
|---|---|---|---|
| 把商品图做成视频 | 缺拍摄与剪辑资源 | 商品图驱动的视频模板 | 更低成本获得动态素材 |
| 把卖点写成脚本 | 不会写钩子、分镜和行动引导 | AI 卖点提炼与脚本生成 | 更快完成营销表达 |
| 为不同平台出版本 | 反复改比例、字幕和语气 | 主脚本派生平台脚本 | 减少重复工作 |
| 生成英文版本 | 直译生硬且可能失真 | 中英对照本地化 | 提高跨境内容可用性 |
| 批量复用成功结构 | 每次重新填参数 | 制作同款与项目资产 | 提高持续生产效率 |

### 6.2 价值曲线

本产品选择强化：

- 商品信息结构化；
- 商业事实确认；
- 多平台脚本与版本管理；
- 中英文本地化确认；
- 商品项目与同款复用。

本产品选择降低：

- 空白提示词的依赖；
- 用户直接面对模型参数的数量；
- 完整视频剪辑的复杂度；
- 单次任务无限扩张的成本风险。

本产品不重点竞争：

- 底层模型数量；
- 纯艺术视频生成；
- 社区内容消费；
- 专业时间轴剪辑。

### 6.3 产品原则

1. **AI 建议，用户确认。** 商品事实、脚本、本地化和模板均保留用户最终决定权。
2. **先结构化，再生成。** 先明确商品、场景、平台和脚本，再调用高成本视频生成。
3. **平台适配不是简单改尺寸。** 需要同时调整语气、节奏、字幕和行动引导。
4. **结果不是终点。** 下载、继续编辑和制作同款共同形成复用闭环。
5. **成本必须提前可见。** 提交前展示视频数量、时长、清晰度和预计额度。

## 7. 产品方案

### 7.1 信息架构

产品采用左侧固定导航的网页端工作台。

```
AI 商品短视频生成工作台
├── 首页
│   ├── 新建入口
│   ├── 最近项目 / 视频
│   ├── 推荐模板
│   └── 生成记录概览
├── 新建视频
│   ├── 1. 商品信息
│   ├── 2. 平台与语言
│   ├── 3. 脚本确认
│   └── 4. 模板与生成设置
├── 模板中心
│   ├── 按营销场景
│   ├── 按商品品类
│   ├── 按平台
│   └── 按语言
├── 资产库
│   ├── 全部视频
│   ├── 按商品
│   ├── 按平台
│   ├── 按语言
│   ├── 已下载 / 收藏
│   └── 生成中 / 失败 / 回收站
└── 账户与额度
    ├── 套餐与余额
    ├── 消耗记录
    ├── 存储情况
    └── 升级入口
```

### 7.2 核心用户流程

#### 7.2.1 商品信息驱动流程

```
首页点击“新建视频”
→ 上传 1–5 张商品图片
→ 填写商品名称与卖点，或粘贴详情页文案
→ AI 提取商品信息、图片用途和推荐营销场景
→ 用户确认商品事实
→ 选择最多 3 个目标平台
→ 系统推荐国内平台中文、海外平台英文
→ AI 生成主脚本与平台适配脚本
→ 用户逐平台确认脚本和中英对照
→ AI 推荐 3 个模板
→ 用户选择模板、时长、清晰度和数量
→ 确认总视频数与额度
→ 提交异步任务
→ 站内通知完成结果
→ 多平台预览、下载、编辑或制作同款
```

#### 7.2.2 模板驱动流程

```
进入模板中心
→ 按场景、品类或平台筛选
→ 查看模板预览
→ 点击“使用模板”
→ 进入新建视频并预填场景、结构和推荐参数
→ 上传商品信息
→ 生成并确认脚本
→ 生成视频
```

#### 7.2.3 制作同款流程

```
进入已完成项目或模板
→ 点击“制作同款”
→ 复用模板、脚本结构、平台、语言和参数
→ 替换商品图片与卖点
→ 用户确认新的商品事实和脚本
→ 提交新任务
```

| P05 | 新建视频：脚本确认 | 校验主脚本、平台脚本和双语内容 |
| P06 | 新建视频：模板与设置 | 选择模板、时长、清晰度与数量 |
| P07 | 生成中 / 任务详情 | 展示多平台任务进度和失败状态 |
| P08 | 视频结果页 | 切换预览平台版本并执行下载、编辑和复用 |
| P09 | 模板中心 | 浏览、筛选和使用模板 |
| P10 | 模板详情 | 展示模板结构、适用品类和预览 |
| P11 | 资产库 | 管理项目、版本和任务状态 |
| P12 | 商品项目详情 | 聚合一个商品的多平台版本 |
| P13 | 账户与额度 | 查看套餐、额度、存储和消耗记录 |
| P14 | 通知中心 | 承接完成、失败、退额和到期提醒 |

### 7.4 关键功能需求

#### 7.4.1 首页

首页是登录后的工作概览，不是营销落地页。

| 模块 | 内容 | 主要操作 |
|---|---|---|
| 快速开始 | 产品价值短句、新建视频、从模板开始 | 进入 P03 / P09 |
| 最近项目 | 最近编辑、生成中、最近完成 | 继续编辑 / 查看结果 |
| 推荐模板 | 按用户历史或热门场景推荐 | 预览 / 使用模板 |
| 记录概览 | 本周任务、成功、失败、剩余额度 | 跳转到资产或额度页 |

“新建视频”是全局主操作，在侧边栏、首页和模板页保持一致入口。

#### 7.4.2 商品图片上传

| 项目 | 规则 |
|---|---|
| 数量 | 1–5 张，至少 1 张 |
| 格式 | JPG、PNG、WEBP |
| 基础操作 | 预览、删除、排序、替换、裁剪、旋转 |
| AI 能力 | 识别商品主体与图片用途 |
| 用户控制 | 可修改用途、顺序、首帧和尾帧 |

AI 可推荐的图片用途：商品主图、商品细节图、使用场景图、包装展示图、首帧、尾帧。

采用“AI 自动判断 + 用户可修改”，避免全部手工标记，也避免错误自动决策无法纠正。

#### 7.4.3 商品名称与卖点

| 字段 | 必填 | 输入方式 | AI 作用 | 用户操作 |
|---|---:|---|---|---|
| 商品名称 | 是 | 手动或 AI 识别 | 从图片 / 文案提取 | 确认、修改、清空 |
| 商品卖点 | 是 | 手动短句或粘贴详情文案 | 提取、去重、结构化、优化 | 对照确认、修改 |
| 价格 / 促销 | 条件必填 | 手动 | 识别但不得猜测 | 确认、修改 |
| 目标人群 | 否 | 标签与自由输入 | 推荐 2–5 个标签 | 增删、补充 |
| 营销场景 | 是 | AI 推荐 | 根据商品和促销信息推荐 | 确认、切换 |

商品名称限制 1–60 个字符。详情页文案在最小可行版本中只支持粘贴文字，不支持读取商品链接。

AI 不得创造商品功效、认证、参数、价格、库存、折扣和活动时间。无法确认的信息需标记并要求用户处理。

#### 7.4.4 AI 卖点优化

输入示例：

```
防水、大容量、可装 15 英寸电脑、轻、适合上班旅行
```

优化示例：

```
防水耐磨材质，保护随身物品；大容量分区可容纳 15 英寸电脑；
轻量设计，适合日常通勤与短途旅行。
```

交互规则：

- 同时展示原文和优化版本；
- 不直接覆盖原文；
- 用户可逐条采用、编辑或删除；
- 标出可能属于推测的信息；
- 价格和促销信息不得被改写成不同事实。

#### 7.4.5 平台与语言

支持平台：抖音、小红书、TikTok、Instagram Reels、YouTube Shorts。

| 平台 | 默认语言 | 适配重点 |
|---|---|---|
| 抖音 | 中文 | 快节奏、强钩子、明确转化 |
| 小红书 | 中文 | 种草、场景化、自然表达 |
| TikTok | 英文 | 短句、强开头、海外表达 |
| Instagram Reels | 英文 | 视觉质感、品牌感 |
| YouTube Shorts | 英文 | 清晰结构、信息可理解性 |

规则：

- 单次最多选择 3 个平台；
- 国内平台默认中文，海外平台默认英文；
- 用户可手动修改，但系统提示推荐关系；
- 进入生成前显示将生成的平台与语言组合。

#### 7.4.6 AI 脚本生成与确认

先生成主脚本，再派生平台版本。

```
主脚本
├── 抖音适配脚本
├── 小红书适配脚本
├── TikTok 适配脚本
├── Instagram Reels 适配脚本
└── YouTube Shorts 适配脚本
```

主脚本保存不应变化的商品事实。平台脚本可调整开头钩子、卖点顺序、字幕长度、语气、节奏、行动引导和建议时长。

每份脚本包含：

| 脚本元素 | 说明 |
|---|---|
| 开头钩子 | 首屏吸引句或问题 |
| 展示顺序 | 商品和卖点的先后逻辑 |
| 分镜说明 | 每个镜头使用哪张图、展示什么 |
| 镜头字幕 | 与画面同步的简短文案 |
| 核心卖点 | 本次重点表达的事实 |
| 行动引导 | 购买、了解或收藏引导 |
| 建议时长 | 5 / 10 / 15 / 30 秒 |

用户可逐平台编辑脚本。修改一个平台版本不影响其他平台，也不覆盖主脚本。

#### 7.4.7 中英文本地化确认

海外平台脚本同时展示中文原文和英文版本。

| 内容 | 中文原文 | 英文版本 | 操作 |
|---|---|---|---|
| 商品标题 | 展示 | 展示 | 编辑英文 |
| 核心卖点 | 展示 | 展示 | 对照确认 |
| 镜头字幕 | 展示 | 展示 | 逐镜头编辑 |
| 行动引导 | 展示 | 展示 | 使用推荐 / 修改 |

系统允许营销化改写，但必须保持商品事实一致。若英文版本遗漏数字、参数、折扣或限定条件，需高亮提示。

#### 7.4.8 模板推荐与模板中心

AI 根据商品品类、营销场景、平台、语言、卖点和促销信息推荐 3 个模板，由用户选择。

模板不是视觉皮肤，而是包含：

- 分镜结构；
- 商品展示逻辑；
- 字幕排版；
- 镜头运动；
- 视频节奏；
- 行动引导位置；
- 平台适配规则；
- 背景音乐风格。

模板卡片字段：

| 字段 | 说明 |
|---|---|
| 模板名称 | 用户可理解的名称 |
| 动态预览 | 展示实际效果 |
| 推荐理由 | 说明与商品 / 场景的匹配原因 |
| 营销场景 | 商品展示、新品、促销、种草 |
| 适用品类 | 美妆、服饰、家居、3C 或通用 |
| 适配平台 | 支持的平台 |
| 支持语言 | 中文、英文或双语 |
| 推荐时长 | 建议视频长度 |
| 操作 | 使用模板、收藏 |

#### 7.4.9 视频参数与任务上限

视频时长由 AI 根据平台、脚本、镜头数量和模板推荐，用户可改为 5、10、15 或 30 秒。

| 参数 | 选项 | 默认 / 规则 |
|---|---|---|
| 清晰度 | 标清 / 高清 / 超清 | 默认高清 |
| 每个平台数量 | 1 / 2 / 4 | 按平台计算 |
| 平台上限 | 最多 3 个 | 超出不可选择 |
| 总视频上限 | 最多 6 条 | 平台数 × 每平台数量 |

示例：

| 平台数 | 每平台数量 | 总数 | 是否允许 |
|---:|---:|---:|---|
| 1 | 4 | 4 | 是 |
| 2 | 2 | 4 | 是 |
| 3 | 2 | 6 | 是 |
| 2 | 4 | 8 | 否 |
| 3 | 4 | 12 | 否 |

提交前必须展示总视频数、时长、清晰度、预计耗时、预计额度和剩余额度。预计耗时与额度倍率为“待定”。

#### 7.4.10 异步生成与状态

任务提交成功后自动进入资产库，用户可以离开页面。

```
草稿
→ 等待提交
→ 排队中
→ 分析商品素材
→ 生成平台脚本
→ 生成视频
→ 字幕与音频合成
→ 渲染导出
→ 部分完成 / 全部完成 / 失败 / 已取消
```

多平台任务支持“部分完成”。例如 3 个平台中 2 个成功，任务显示“已完成 2/3”，用户可单独重试失败平台。

#### 7.4.11 站内通知

最小可行版本仅做站内通知。

| 触发场景 | 通知示例 |
|---|---|
| 全部完成 | 你的商品视频已全部生成完成 |
| 部分完成 | 3 个平台中已有 2 个生成成功 |
| 失败 | TikTok 版本生成失败，请查看原因 |
| 退还额度 | 失败版本消耗的额度已退回 |
| 即将过期 | 该视频将在 3 天后到期，请及时下载 |
| 回收站清理 | 该项目将在 1 天后永久删除 |

#### 7.4.12 结果页

结果页按平台标签页切换：

```
抖音｜小红书｜TikTok｜Instagram｜YouTube Shorts
```

每个平台版本展示播放器、比例、时长、标题、字幕、行动引导、语言、模板、时间和额度。

| 操作 | 行为 | 是否消耗额度 |
|---|---|---:|
| 播放预览 | 在线查看当前版本 | 否 |
| 下载 | 下载当前版本或批量下载 | 否 |
| 重新生成 | 保留当前配置重新调用模型 | 是 |
| 复制设置 | 复制商品、脚本、模板和参数配置 | 否 |
| 制作同款 | 创建新项目并复用结构 | 生成时消耗 |
| 继续编辑 | 返回对应步骤修改后重新生成 | 生成时消耗 |
| 字幕编辑 | 修改文字、位置、字号和基础样式 | 重新渲染规则待定 |
| 收藏 / 标签 | 管理自动保存的资产 | 否 |
| 删除 | 删除版本或项目并进入回收站 | 否 |

#### 7.4.13 资产库

生成任务和结果默认自动保存。结果页不再提供“保存到资产库”，改为收藏、归档或添加标签。

资产库支持：全部视频、按商品、按平台、按语言、已下载、生成中、失败、收藏和回收站。

建议以商品项目聚合版本：

```
通勤双肩包项目
├── 抖音中文版 A / B
├── 小红书中文版
└── TikTok 英文版方案一 / 方案二
```

资产卡片字段：视频封面、商品名称、营销场景、平台、语言、时长、创建时间、状态、下载状态、收藏状态和快捷操作。

#### 7.4.14 制作同款

制作同款复用：

- 模板；
- 脚本结构；
- 镜头顺序；
- 平台与语言；
- 时长与清晰度；
- 字幕样式；
- 行动引导位置；
- 音乐风格；
- 其他生成参数。

用户必须替换或重新确认商品图片、商品名称、卖点、价格和促销信息。系统不得把原商品事实自动带入新商品并直接生成。

#### 7.4.15 简单字幕编辑

最小可行版本支持：

- 修改字幕文字；
- 调整字幕位置；
- 选择基础字幕样式；
- 调整字号；
- 开启或关闭字幕；
- 修改行动引导文字。

最小可行版本不支持多轨时间轴、视频裁剪、拼接、复杂转场、专业调色和音频时间轴。

### 7.5 业务规则

#### 7.5.1 账户与免费体验

- 用户需注册后生成；
- 注册赠送一次完整生成体验；
- 免费用户每月获得少量额度，具体数量待定；
- 个人账号为最小可行版本唯一账号形态；
- 团队空间和权限不在最小可行版本中提供。

#### 7.5.2 收费模式

采用月度订阅加额外额度包。

会员权益可包括更多额度、无水印、超清、长期保存、更高并发、更多模板和优先队列。套餐价格与权益数量待定。

#### 7.5.3 额度计算

```
任务额度
= 单条视频基础额度
× 视频数量
× 清晰度系数
× 时长系数
```

倍率待定。用户侧使用固定、可预测的点数；模型实际成本在后台单独核算。

#### 7.5.4 水印

- 免费用户下载带产品水印；
- 会员用户无水印；
- 水印不得遮挡商品主体，建议位于角落或尾帧；
- 在线预览是否带水印由设计和防滥用策略决定，当前待定。

#### 7.5.5 保存与删除

| 用户 / 状态 | 规则 |
|---|---|
| 免费用户 | 视频文件保存 30 天 |
| 会员用户 | 账号正常且未主动删除时长期保存 |
| 到期后 | 可删除成片，但保留必要项目配置，具体保留期待定 |
| 删除 | 进入回收站 7 天 |
| 永久删除 | 7 天后自动执行，不可恢复 |

免费作品到期前 7 天和 3 天提醒。回收站清理前 1 天提醒。

#### 7.5.6 失败与额度退还

| 失败原因 / 阶段 | 额度处理 |
|---|---|
| 模型、系统、渲染或平台适配失败 | 退还失败版本额度 |
| 多平台部分失败 | 只退失败版本 |
| 排队中取消 | 全额退还 |
| 素材分析阶段取消 | 全额或大部分退还，比例待定 |
| 已进入视频生成后取消 | 不退或部分退还，比例待定 |
| 生成成功但主观不满意 | 不退还 |
| 素材违规 | 是否退还由审核成本决定，当前待定 |

### 7.6 异常状态

#### 7.6.1 输入与任务异常

| 异常 | 用户提示 | 可执行操作 |
|---|---|---|
| 未上传图片 | 请上传至少 1 张商品图片 | 上传图片 |
| 超过 5 张 | 每个商品最多上传 5 张 | 删除多余图片 |
| 格式不支持 | 请上传 JPG、PNG 或 WEBP | 重新上传 |
| 图片模糊 | 图片清晰度较低，可能影响生成效果 | 更换 / 继续 |
| 无法识别主体 | 请上传主体更清晰的商品图片 | 更换图片 |
| 商品名称为空 | 请填写商品名称 | 返回填写 |
| 商品卖点为空 | 请至少填写一个卖点 | 添加卖点 |
| 促销信息缺失 | 限时促销需填写价格或活动信息 | 补充信息 |
| 超过 3 个平台 | 单次最多选择 3 个平台 | 取消部分平台 |
| 超过 6 条视频 | 当前配置超过 6 条上限 | 减少平台 / 数量 |
| 额度不足 | 展示预计消耗与余额差额 | 降清晰度 / 减数量 / 购买 |

#### 7.6.2 AI 内容异常

系统需要检查并高亮：

- AI 推测的商品功能；
- 数字、规格、认证或价格与原文不一致；
- 中英文商品事实不一致；
- 字幕过长或与时长不匹配；
- 行动引导缺失；
- 促销有效期缺失；
- 平台脚本只有尺寸差异，没有内容适配；
- 内容安全或版权风险。

高风险字段未确认时，“确认并生成”按钮不可用。

#### 7.6.3 生成异常

| 状态 | 处理 |
|---|---|
| 排队过久 | 展示预计等待，允许离开和取消 |
| 单平台失败 | 保留成功版本，可单独重试失败版本 |
| 全部失败 | 展示原因、退额结果和修改建议 |
| 渲染失败 | 自动重试一次，仍失败则退额 |
| 网络中断 | 服务端任务继续，恢复后同步状态 |
| 通知未读 | 首页和资产库持续展示状态 |

### 7.7 数据埋点与指标

#### 7.7.1 核心漏斗

```
进入工作台
→ 点击新建 / 使用模板
→ 完成商品信息
→ 确认脚本
→ 提交任务
→ 首条视频生成完成
→ 下载
→ 制作同款
```

| 阶段 | 事件 / 指标 |
|---|---|
| 首页 | 点击新建视频、点击使用模板 |
| 商品信息 | 完成商品信息、使用 AI 卖点优化 |
| 平台与语言 | 选择平台、修改推荐语言 |
| 脚本 | 生成脚本、编辑脚本、确认脚本 |
| 模板 | 展示推荐模板、选择模板 |
| 任务 | 提交生成、全部完成、部分完成、生成失败 |
| 结果 | 预览视频、下载视频、编辑字幕 |
| 复用 | 点击制作同款、完成同款生成、下载同款视频 |

#### 7.7.2 核心指标口径

1. **首条视频生成完成率**

```
成功生成首条视频的新用户数
÷ 进入新建视频流程的新用户数
```

2. **视频下载率**

```
被下载的视频数量
÷ 成功生成的视频数量
```

3. **多平台版本生成完成率**

```
全部目标平台均成功生成的任务数
÷ 提交多平台生成的任务数
```

同时观察部分成功率、平台失败率和中英文版本差异。

4. **制作同款使用率**

```
点击制作同款的已完成项目数
÷ 被查看的已完成项目数
```

辅助指标包括同款生成完成率、同款后下载率、脚本编辑率、AI 卖点采用率、平均任务视频数和额度购买转化率。

### 7.8 技术与系统要求

本 PRD 不指定具体模型供应商，但系统需要具备以下能力边界：

- 商品文本抽取与结构化；
- 图片主体与用途识别；
- 主脚本和平台脚本生成；
- 中英文本地化与事实一致性检查；
- 模板与脚本编排；
- 异步视频生成和渲染；
- 多平台子任务状态管理；
- 内容安全审核；
- 额度计费和失败补偿；
- 视频、图片、脚本和配置的资产管理。

#### 非功能需求

| 类别 | 要求 |
|---|---|
| 可用性 | 四步流程可保存草稿并返回修改 |
| 状态一致性 | 刷新或换页后任务状态不丢失 |
| 性能 | 普通表单操作响应目标 < 1 秒；AI 和视频任务显示进度与预计时间 |
| 可靠性 | 多平台子任务独立，单个失败不影响成功版本 |
| 安全 | 上传素材私有访问，下载链接具备有效期 |
| 隐私 | 明确素材是否用于模型训练，默认不应未经授权用于训练 |
| 合规 | 审核商品功效、版权、人物肖像、商标和禁售内容 |
| 可追踪 | 保存模型版本、模板版本、脚本版本和任务日志 |

### 7.9 关键假设与验证计划

| 假设 | 风险 | 验证方式 |
|---|---|---|
| 用户愿意先确认脚本再生成 | 多一步可能降低提交率 | 5–8 人可用性测试；对比直接生成与脚本确认流程 |
| 多平台适配有明显价值 | 结果可能只改尺寸，用户不认可 | 让运营人员盲评不同平台脚本与视频差异 |
| 中英对照能降低本地化风险 | 用户可能看不懂英文或懒得确认 | 观察确认时长、编辑率和错误反馈 |
| 推荐 3 个模板能降低选择成本 | 可能仍造成犹豫 | 观察模板选择时长与放弃率 |
| 制作同款能带来复用 | 用户可能只生成一次 | 追踪同款使用率和同款后下载率 |
| 商品图可稳定生成可用视频 | 主体可能变形或不一致 | 分品类建立质量评审集与人工评分 |
| 用户接受额度计费 | 成本可能难理解 | 生成前价格可理解性测试与转化测试 |

## 8. 发布计划

### 8.1 最小可行版本范围

#### 必须包含

- 注册、登录、个人账号和首次完整体验；
- 首页工作概览、站内通知、账户与额度；
- 1–5 张商品图片上传、预览、排序、裁剪、旋转和用途识别；
- 商品名称识别、卖点填写、详情文案粘贴和 AI 卖点优化；
- 商品展示、新品发布、限时促销、种草推荐；
- 抖音、小红书、TikTok、Instagram Reels、YouTube Shorts；
- 单次最多 3 个平台，国内默认中文、海外默认英文；
- 主脚本、平台脚本、中英对照和人工确认；
- AI 推荐 3 个模板；
- 5 / 10 / 15 / 30 秒、标清 / 高清 / 超清、每平台 1 / 2 / 4 条；
- 单次最多 6 条视频；
- 异步生成、部分完成、失败重试与额度退还；
- 多平台结果预览、下载、重新生成、复制设置、制作同款；
- 简单字幕编辑；
- 项目自动保存、收藏、回收站和保存期限；
- 免费水印、订阅与额度包的基础规则；
- 核心埋点和四个核心指标。

#### 最小可行版本不包含

- 多商品批量上传与批量生成；
- 批量制作同款；
- 除中英文外的更多语言；
- 商品详情页链接自动解析；
- 团队空间、成员权限和审批；
- 品牌标识、字体、品牌色资产库；
- 完整视频时间轴剪辑；
- 平台一键发布；
- 广告投放数据回流和自动优化；
- 外部接口接入；
- 社区和公开作品页。

### 8.2 建议发布阶段

不承诺具体日期，以下为相对阶段建议。

#### 阶段 0：需求验证，约 2–3 周

- 访谈 5–8 名电商 / 跨境 / 内容运营用户；
- 用低保真原型测试四步流程；
- 验证脚本确认、多平台选择和额度理解；
- 选取四类商品建立样例数据集；
- 明确底层模型可支持的时长、分辨率和主体一致性。

**退出条件：** 至少 70% 的测试用户能独立完成任务配置；主要字段和脚本确认无严重理解问题。

#### 阶段 1：内部测试，约 6–8 周

- 完成单商品、单平台、单语言主流程；
- 接入商品信息抽取、脚本、模板和一种视频生成链路；
- 建立任务状态、资产和基础额度；
- 首批模板覆盖四个品类和四个营销场景。

**退出条件：** 主流程稳定，生成任务可追踪，系统失败能正确退额。

#### 阶段 2：封闭测试，约 4–6 周

- 开放最多 3 个平台、中文和英文；
- 支持平台脚本、中英对照、部分成功和多版本结果页；
- 上线免费水印、订阅和额度包测试；
- 收集核心漏斗和质量反馈。

**退出条件：** 达到校准后的生成完成率、下载率和多平台完成率门槛；无高频商品事实错误。

#### 阶段 3：最小可行版本发布与优化

- 根据封闭测试数据调整模板推荐、额度、默认时长和清晰度；
- 优化失败原因、重试和通知；
- 验证制作同款的持续使用价值；
- 决定是否进入批量商品与更多语言。

### 8.3 后续优先方向

#### 方向一：更多语言本地化

扩展日语、韩语、西班牙语、法语、德语和葡萄牙语。重点是本地化钩子、行动引导、字幕长度和商品事实校验，不只是翻译。

#### 方向二：批量上传多个商品

通过表格或批量任务列表上传多个商品，适配店铺上新、多商品款式和节日促销。

#### 方向三：批量制作同款

选择一个满意视频，批量替换多个商品的图片和卖点，复用模板、脚本结构和参数。

后续再评估团队空间、品牌资产、平台发布、详情页链接解析和投放数据回流。

### 8.4 待定项

以下内容需要结合模型成本、技术能力、用户测试和商业实验后确定：

- 每月免费额度数量；
- 套餐价格和权益；
- 清晰度与时长的额度倍率；
- 输出分辨率；
- 各类任务预计生成时间；
- 并发任务上限；
- 存储空间上限；
- 取消任务的部分退额比例；
- 字幕修改后的重新渲染成本；
- 视频到期后项目配置的保留期限。

### 8.5 作品集总结

本项目体现的 AI 产品经理能力不在于提出一个新的“生成视频”按钮，而在于：

1. 在成熟模型平台环境中收窄到电商营销场景；
2. 将商品输入、脚本、平台、语言和模板结构化；
3. 用“AI 推荐 + 用户确认”处理效率与商业准确性的冲突；
4. 将多平台任务拆成可独立成功、失败和退额的子任务；
5. 通过制作同款和商品项目资产建立结果复用机制；
6. 明确最小可行版本不做专业剪辑、团队协作和投放闭环；
7. 用完成率、下载率、多平台成功率和同款使用率验证价值。

最终，本产品不是重新发明 AI 视频模型，而是把已有 AI 能力产品化为一套面向电商营销的可控生产工作流。
